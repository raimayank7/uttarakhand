How the code USCB0001006 is built

USCB is the bank part: the letters of UTTARAKHAND STATE COOPERATIVE BANK LIMITED. The fifth character is always the digit 0. 001006 is the part that names this branch.

The MICR code 244554202 is the number printed along the bottom of this branch's cheques. 244 is the city (the same three digits that begin the PIN code 244713), 554 is the bank and 202 is the branch.
