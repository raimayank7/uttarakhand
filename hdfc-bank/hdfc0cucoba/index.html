How the code HDFC0CUCOBA is built

HDFC is the bank part: the letters of HDFC Bank. The fifth character is always the digit 0. CUCOBA is the part that names this branch.

The MICR code 248809103 is the number printed along the bottom of this branch's cheques. 248 is the city (the same three digits that begin the PIN code 248140), 809 is the bank and 103 is the branch.
